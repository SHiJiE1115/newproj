# Included sources and preparation status

This directory contains five Python verification programs, five small JSON or
compressed-JSON mathematical data files, a written fixed-source submodular proof,
this notice, a usage guide and an exact file manifest. The programs comprise a
dispatcher, two entrypoints and two reused mathematical kernels. All ten
execution files retain their source bytes. They use the Python standard library;
the runtime itself is not included. Repackaging does not create an independent
implementation or a new mathematical result.

The mathematical data are finite combinatorial frontiers, policy witnesses and
rational proof certificates. They do not identify human research participants or
authenticate anyone's historical scientific activity. Only the proof note's
package-location paragraph is adapted; its mathematical body is unchanged.

A bounded project source-lineage review traced the included verifier lineage to
the project's recorded verification scripts and adapters and found no direct
dependency on the original uploaded prototype in that inspected chain. This is
a dependency finding, not proof of original authorship, complete third-party
attribution, legal ownership or permission to publish. Original source and
transformation records remain outside this proposed repository subtree.

No manuscript, PDF, publisher template, bibliography style, external research
paper, Python binary or hidden data file is included. There is no claim that an
absent manuscript or provenance directory can be opened from this package.
