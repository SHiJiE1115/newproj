# Prospective Wine author run with raw strace

This is a **local, unpublished candidate** for one GitHub-hosted Ubuntu experiment. It downloads and verifies the exact public author-code archive and UCI Wine input, builds a Docker image, and runs the unchanged author learning/pruning code through a compatibility caller for 25 fixed splits. The container has no network, a read-only root filesystem, dropped capabilities, and only the result and trace paths writable. Raw `strace` captures selected file, read, process-start, and connection syscalls.

The first job retains success or failure receipts. A second VM verifies the source snapshot, input pins, the returned 25-row CSV and arithmetic, and positive `openat`/`read` events for the Wine file before asking GitHub to attest the receipt tar. The repository does not include the author archive, UCI data, API keys, human labels, or historical execution evidence.

The target is Leboeuf et al., NeurIPS 2020, Table 1 Wine/Ours, reported as `0.904 ± 0.046`. The Wine data were used to choose the prior exponent in the paper, so this is not an independent blind test of that number. A successful workflow would add a **new prospective execution observation** tied to a GitHub workflow identity. It would not prove a complete byte-level readset, authenticate the original 2020 run, establish scientific ground truth, or show an advantage over a same-information fixed baseline.

The workflow is manual (`workflow_dispatch`) and has **not run**. This candidate has no remote. The runner's source-byte freeze is in `experiment/FREEZE.json`; the GitHub workflow will fail closed if a frozen file changes. The verified author ZIP and UCI data are fetched at run time from the pinned URLs in `experiment/PROTOCOL.json`. Ubuntu base-image digest is pinned; apt package versions are observed and recorded during the build/run, not byte-pinned in this v01 candidate.

After authorization and publication in a user-controlled public repository, choose **Actions → RRNC prospective Wine author strace → Run workflow**. The job is capped at 25 minutes; the container author step at 300 seconds. Download and preserve the artifact and attestation because Actions artifacts expire. A failure is retained as a capability failure and must not be called a successful trace. The original P1 release gate and local reserve set are unchanged.
