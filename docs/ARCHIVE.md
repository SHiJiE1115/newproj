## Why the root README is retained

The [root README](../README.md) is an early Wine preparation note whose bytes are included in a historical source freeze. It is preserved for compatibility. GitHub displays the new `.github/README.md` as the repository landing page, so readers can begin with the current theory materials while the historical source remains intact.

Package READMEs and execution records describe the state at their original deposit. Later outcomes are linked from the new [reproduction guide](REPRODUCING.md); historical statements and signed or hashed records are not rewritten retrospectively.
